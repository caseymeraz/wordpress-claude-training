# Week 2: WordPress Patterns (ACF & Gutenberg)

Welcome to Week 2! This week focuses on building WordPress features with Claude Code. You'll create ACF field groups, build a Gutenberg block, and learn to use the WordPress Skills package for quality checks.

## Learning Objectives

- Create ACF field groups using Claude Code
- Build basic Gutenberg block with server-side rendering
- Install and use WordPress Skills package
- Practice iterative refinement with Claude

## Time Commitment

- Exercise 1: 30 minutes (ACF Field Group)
- Exercise 2: 45 minutes (Gutenberg Block)
- Exercise 3: 30 minutes (WordPress Skills)
- **Total: ~2 hours**

---

## Exercise 1: ACF Field Group Creation (30 min)

**Task:** Create a "Team Member Details" field group for a team member custom post type.

**Requirements:**
- Field group name: "Team Member Details"
- Location: Post type equals `team_member`
- Fields to include:
  - Job Title (text field)
  - Bio (textarea, 3 rows)
  - LinkedIn URL (url field)
  - Photo (image field, return format: array)
  - Featured Employee (true/false)
- Create a template file to display all fields with proper escaping
- Fields should appear in post editor

**Success Criteria:**
- ✅ Field group appears in ACF admin
- ✅ All 5 fields present with correct types
- ✅ Fields save correctly when editing team member post
- ✅ Template displays all fields with proper escaping functions
- ✅ No PHPCS violations

**Skills Practiced:**
- ACF configuration
- Template integration
- WordPress escaping functions
- Asking Claude for specific field configurations

**Tips:**
- Use Claude to generate the ACF field group JSON
- Ask Claude to create the template file with proper escaping
- Test by creating a team member post and viewing it

## Exercise 2: Simple Gutenberg Block (45 min)

**Task:** Create a "Featured Posts" dynamic block that displays recent posts from a selected category.

**Requirements:**
- Block name: "Featured Posts"
- Block category: "widgets"
- Settings:
  - Category selector (dropdown of all categories)
  - Number of posts to show (number input, default: 3)
  - Show thumbnails (toggle, default: true)
- Server-side rendering
- Display post title, excerpt, and thumbnail (if enabled)
- Link each post to its permalink

**Success Criteria:**
- ✅ Block appears in block inserter
- ✅ Block settings work in editor sidebar
- ✅ Block displays correct posts on frontend
- ✅ Thumbnails toggle works
- ✅ Category selector filters posts correctly
- ✅ Code follows WordPress block standards

**Skills Practiced:**
- Gutenberg block architecture
- Server-side rendering
- Block attributes and controls
- Dynamic WordPress queries
- Working with WP_Query

**Tips:**
- Ask Claude to scaffold the complete block structure
- Use `registerBlockType` with `render_callback`
- Test with different categories and post counts
- Preview changes in the editor

## Exercise 3: Install WordPress Skills & Performance Audit (30 min)

**Task:** Install the WordPress Skills package and run your first performance audit.

**Requirements:**
- Install `elvismdev/claude-wordpress-skills` package
- Run `/wp-perf-review` on your theme or plugin code
- Review the performance report
- Fix at least one performance issue identified
- Document the fix in your CLAUDE.md

**Success Criteria:**
- ✅ Skills package installed successfully
- ✅ `/wp-perf-review` command works
- ✅ Performance report generated with findings
- ✅ At least one issue fixed (code improvement made)
- ✅ Fix documented with before/after code

**Skills Practiced:**
- Installing Claude Code plugins
- Using skills commands
- Performance optimization awareness
- Code improvement iteration

**Tips:**
- Skills install: In Claude Code, use `/plugin marketplace add elvismdev/claude-wordpress-skills`
- Run audit: `/wp-perf-review wp-content/themes/your-theme`
- Common findings: N+1 queries, missing caching, unoptimized hooks
- Ask Claude to explain any findings you don't understand
