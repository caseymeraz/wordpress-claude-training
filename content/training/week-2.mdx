Welcome to Week 2! This week focuses on building WordPress features with Claude Code. You'll create ACF field groups, build a Gutenberg block, and learn to use the WordPress Skills package for quality checks.

## Exercise 1: ACF Field Group Creation (30 min)

**Task:** Create a "Team Member Details" field group for a team member custom post type.

**Requirements:**
- Field group name: "Team Member Details"
- Location: Post type equals `team_member`
- Fields to include:
  - Job Title (text field)
  - Bio (textarea, 3 rows)
  - LinkedIn URL (url field)
  - Photo (image field, return format: array)
  - Featured Employee (true/false)
- Create a template file to display all fields with proper escaping
- Fields should appear in post editor

**Success Criteria:**
- ✅ Field group appears in ACF admin
- ✅ All 5 fields present with correct types
- ✅ Fields save correctly when editing team member post
- ✅ Template displays all fields with proper escaping functions
- ✅ No PHPCS violations

**Skills Practiced:**
- ACF configuration
- Template integration
- WordPress escaping functions
- Asking Claude for specific field configurations

**Tips:**
- Use Claude to generate the ACF field group JSON
- Ask Claude to create the template file with proper escaping
- Test by creating a team member post and viewing it

## Exercise 2: Simple Gutenberg Block (45 min)

**Task:** Create a "Featured Posts" dynamic block that displays recent posts from a selected category.

**Requirements:**
- Block name: "Featured Posts"
- Block category: "widgets"
- Settings:
  - Category selector (dropdown of all categories)
  - Number of posts to show (number input, default: 3)

- Display post title, excerpt, and thumbnail (if enabled)
- Link each post to its permalink

**Success Criteria:**
- ✅ Block appears in block inserter
- ✅ Block settings work in editor sidebar
- ✅ Block displays correct posts on frontend
- ✅ Thumbnails toggle works
- ✅ Category selector filters posts correctly

**Skills Practiced:**
- Gutenberg block architecture

**Tips:**

### Part 2: ACF Field Group Creation (30 min)

**Prompt for Claude:**
```
Create ACF field groups for this Services page:

Hero Section:
- Background image
- Headline (h1)
- Subheadline (p)

Services (repeatable):
- Icon (image)
- Service title
- Service description

CTA Section:
- CTA headline
- Button text
- Button URL

Use best practices:
- Group fields logically
- Use appropriate field types
- Add helpful instructions for editors
- Consider the WordPress editor experience
```

**Expected Claude Output:**

Complete ACF PHP code following this structure:

```php
<?php
/**
 * Services Page ACF Field Groups
 */

acf_add_local_field_group(array(
    'key' => 'group_services_page',
    'title' => 'Services Page Fields',
    'fields' => array(
        // Hero Group
        array(
            'key' => 'field_hero_group',
            'label' => 'Hero Section',
            'name' => 'hero_section',
            'type' => 'group',
            'instructions' => 'Main hero section content',
            'sub_fields' => array(
                array(
                    'key' => 'field_hero_bg',
                    'label' => 'Background Image',
                    'name' => 'background_image',
                    'type' => 'image',
                    'instructions' => 'Recommended size: 1920x800px',
                    'return_format' => 'array',
                    'preview_size' => 'medium',
                ),
                array(
                    'key' => 'field_hero_headline',
                    'label' => 'Headline',
                    'name' => 'headline',
                    'type' => 'text',
                    'instructions' => 'Main page headline (h1)',
                ),
                array(
                    'key' => 'field_hero_subheadline',
                    'label' => 'Subheadline',
                    'name' => 'subheadline',
                    'type' => 'textarea',
                    'rows' => 2,
                    'instructions' => 'Supporting text under headline',
                ),
            ),
        ),
        // Services Repeater
        array(
            'key' => 'field_services_repeater',
            'label' => 'Services',
            'name' => 'services',
            'type' => 'repeater',
            'instructions' => 'Add 3-6 services',
            'sub_fields' => array(
                array(
                    'key' => 'field_service_icon',
                    'label' => 'Service Icon',
                    'name' => 'icon',
                    'type' => 'image',
                    'instructions' => 'Square icon, 200x200px recommended',
                    'return_format' => 'array',
                ),
                array(
                    'key' => 'field_service_title',
                    'label' => 'Service Title',
                    'name' => 'title',
                    'type' => 'text',
                ),
                array(
                    'key' => 'field_service_desc',
                    'label' => 'Service Description',
                    'name' => 'description',
                    'type' => 'textarea',
                    'rows' => 3,
                ),
            ),
            'min' => 3,
            'max' => 6,
            'layout' => 'block',
            'button_label' => 'Add Service',
        ),
        // CTA Group
        array(
            'key' => 'field_cta_group',
            'label' => 'Call to Action',
            'name' => 'cta_section',
            'type' => 'group',
            'sub_fields' => array(
                array(
                    'key' => 'field_cta_headline',
                    'label' => 'CTA Headline',
                    'name' => 'headline',
                    'type' => 'text',
                ),
                array(
                    'key' => 'field_cta_button_text',
                    'label' => 'Button Text',
                    'name' => 'button_text',
                    'type' => 'text',
                    'default_value' => 'Get Started',
                ),
                array(
                    'key' => 'field_cta_button_url',
                    'label' => 'Button URL',
                    'name' => 'button_url',
                    'type' => 'url',
                ),
            ),
        ),
    ),
    'location' => array(
        array(
            array(
                'param' => 'page_template',
                'operator' => '==',
                'value' => 'template-services.php',
            ),
        ),
    ),
));
```

**Best Practices Highlighted:**
- **Group fields** for related content (hero_section, cta_section)
- **Repeater fields** for dynamic lists (services)
- **Helpful instructions** for content editors
- **Min/max limits** to maintain design integrity
- **Return formats** optimized for template usage
- **Location rules** to attach fields to specific templates

### Part 3: WordPress Template Creation (30 min)

**Prompt for Claude:**
```
Create a WordPress page template that uses the ACF fields we defined.

Requirements:
- Use modern WordPress best practices
- Pixel-perfect match to Figma design (assume desktop-first, then responsive)
- Fully responsive (mobile, tablet, desktop)
- Accessible HTML (proper heading hierarchy, alt text)
- Optimized images (use WordPress image sizes, lazy loading)
- Proper escaping for all output

Output:
1. template-services.php (complete template)
2. Associated CSS/SCSS for the page
3. Any required JavaScript (if needed)
```

**Expected Claude Output:**

```php
<?php
/**
 * Template Name: Services Page
 *
 * @package YourTheme
 */

get_header();

// Get ACF fields
$hero = get_field('hero_section');
$services = get_field('services');
$cta = get_field('cta_section');
?>

<main id="main-content" class="services-page">

    <?php if ($hero) : ?>
    <!-- Hero Section -->
    <section class="hero-section" style="background-image: url('<?php echo esc_url($hero['background_image']['url']); ?>')">
        <div class="container">
            <div class="hero-content">
                <h1 class="hero-headline"><?php echo esc_html($hero['headline']); ?></h1>
                <p class="hero-subheadline"><?php echo esc_html($hero['subheadline']); ?></p>
            </div>
        </div>
    </section>
    <?php endif; ?>

    <?php if ($services) : ?>
    <!-- Services Section -->
    <section class="services-section">
        <div class="container">
            <div class="services-grid">
                <?php foreach ($services as $service) : ?>
                    <div class="service-card">
                        <?php if ($service['icon']) : ?>
                            <img src="<?php echo esc_url($service['icon']['sizes']['medium']); ?>"
                                 alt="<?php echo esc_attr($service['title']); ?> icon"
                                 class="service-icon"
                                 loading="lazy">
                        <?php endif; ?>
                        <h3 class="service-title"><?php echo esc_html($service['title']); ?></h3>
                        <p class="service-description"><?php echo esc_html($service['description']); ?></p>
                    </div>
                <?php endforeach; ?>
            </div>
        </div>
    </section>
    <?php endif; ?>

    <?php if ($cta) : ?>
    <!-- CTA Section -->
    <section class="cta-section">
        <div class="container">
            <div class="cta-content">
                <h2 class="cta-headline"><?php echo esc_html($cta['headline']); ?></h2>
                <a href="<?php echo esc_url($cta['button_url']); ?>"
                   class="btn btn-primary">
                    <?php echo esc_html($cta['button_text']); ?>
                </a>
            </div>
        </div>
    </section>
    <?php endif; ?>

</main>

<?php get_footer(); ?>
```
