## Exercise 1: Custom REST API Endpoints with JWT Authentication (45 min)

**Task:** Create secure custom REST API endpoints for a headless WordPress application with JWT token-based authentication.

**Context:** When building headless WordPress, you'll need custom API endpoints that go beyond what the default REST API provides. JWT (JSON Web Tokens) provide secure, stateless authentication perfect for decoupled frontends.

### Requirements

1. Install JWT Authentication plugin
2. Configure JWT secret key
3. Create custom REST API endpoint
4. Implement JWT token validation
5. Add proper error handling and security
6. Test with curl or Postman

### Part 1: JWT Authentication Setup (15 min)

**Install JWT Plugin:**
```bash
# Via WP-CLI
wp plugin install jwt-authentication-for-wp-rest-api --activate

# Or manually from:
# https://wordpress.org/plugins/jwt-authentication-for-wp-rest-api/
```

**Configure wp-config.php:**
```php
// Add JWT secret key
define('JWT_AUTH_SECRET_KEY', 'your-top-secret-key-here');

// Enable JWT CORS support
define('JWT_AUTH_CORS_ENABLE', true);
```

**Test Authentication Endpoint:**
```bash
curl -X POST https://your-site.com/wp-json/jwt-auth/v1/token \
  -d "username=admin&password=your-password"
```

**Expected Response:**
```json
{
  "token": "eyJ0eXAiOiJKV1QiLCJhbGc...",
  "user_email": "admin@example.com",
  "user_nicename": "admin",
  "user_display_name": "Admin"
}
```

### Part 2: Create Custom REST API Endpoint (20 min)

Ask Claude to create a custom endpoint:

**Prompt:**
> Create a custom WordPress REST API endpoint at /wp-json/myapp/v1/posts that:
> 1. Returns posts with custom fields
> 2. Requires JWT authentication
> 3. Accepts query parameters (posts_per_page, category)
> 4. Returns proper error responses
> 5. Includes custom meta data in response

**Example Implementation:**
```php
<?php
// File: wp-content/plugins/my-api/includes/class-api-posts.php

class MyApp_API_Posts {

    public function register_routes() {
        register_rest_route('myapp/v1', '/posts', array(
            'methods'             => 'GET',
            'callback'            => array($this, 'get_posts'),
            'permission_callback' => array($this, 'verify_jwt'),
            'args'                => array(
                'posts_per_page' => array(
                    'default'           => 10,
                    'sanitize_callback' => 'absint',
                ),
                'category' => array(
                    'default'           => '',
                    'sanitize_callback' => 'sanitize_text_field',
                ),
            ),
        ));
    }

    public function verify_jwt($request) {
        // JWT plugin handles token validation
        $user_id = get_current_user_id();

        if (!$user_id) {
            return new WP_Error(
                'rest_forbidden',
                __('You must be authenticated to access this endpoint.'),
                array('status' => 401)
            );
        }

        return true;
    }

    public function get_posts($request) {
        $args = array(
            'posts_per_page' => $request['posts_per_page'],
            'post_status'    => 'publish',
        );

        if (!empty($request['category'])) {
            $args['category_name'] = $request['category'];
        }

        $query = new WP_Query($args);
        $posts = array();

        if ($query->have_posts()) {
            while ($query->have_posts()) {
                $query->the_post();

                $posts[] = array(
                    'id'            => get_the_ID(),
                    'title'         => get_the_title(),
                    'excerpt'       => get_the_excerpt(),
                    'content'       => get_the_content(),
                    'date'          => get_the_date('c'),
                    'author'        => get_the_author(),
                    'featured_image' => get_the_post_thumbnail_url(get_the_ID(), 'large'),
                    'categories'    => wp_get_post_categories(get_the_ID(), array('fields' => 'names')),
                    'custom_fields' => array(
                        'subtitle'    => get_post_meta(get_the_ID(), 'subtitle', true),
                        'read_time'   => get_post_meta(get_the_ID(), 'read_time', true),
                    ),
                );
            }
        }

        wp_reset_postdata();

        return rest_ensure_response(array(
            'posts' => $posts,
            'total' => $query->found_posts,
            'pages' => $query->max_num_pages,
        ));
    }
}

// Initialize
add_action('rest_api_init', function() {
    $api = new MyApp_API_Posts();
    $api->register_routes();
});
```

```php

// File: wp-content/plugins/my-cpts/team-members.php

function register_team_member_cpt() {
    register_post_type('team_member', array(
        'labels' => array(
            'name' => __('Team Members'),
            'singular_name' => __('Team Member'),
        ),
        'public'       => true,
        'show_in_rest' => true,

        // WPGraphQL settings
        'show_in_graphql'     => true,
        'graphql_single_name' => 'teamMember',
        'graphql_plural_name' => 'teamMembers',

        'supports' => array('title', 'editor', 'thumbnail', 'custom-fields'),
    ));
}
add_action('init', 'register_team_member_cpt');
```

### Part 4: Efficient Query Patterns (10 min)

**Bad Query (N+1 Problem):**
```graphql
query {
  posts {
    nodes {
      id
      title
      # Each post triggers separate query for author
      author {
        node {
          name
        }
      }
      # Each post triggers separate query for categories
      categories {
        nodes {
          name
        }
      }
    }
  }
}
```

**Optimized Query:**
```graphql
query GetPostsOptimized($first: Int = 10) {
  posts(first: $first) {
    nodes {
      id
      title
      excerpt
      date
      author {
        node {
          id
          name
          avatar {
            url
          }
        }
      }
      categories {
        nodes {
          id
          name
          slug
        }
      }
      featuredImage {
        node {
          id
          sourceUrl(size: LARGE)
          altText
        }
      }
    }
    pageInfo {
      hasNextPage
      endCursor
    }
  }
}
```

**Pagination Query:**
```graphql
query GetMorePosts($after: String, $first: Int = 10) {
  posts(first: $first, after: $after) {
    nodes {
      id
      title
    }
    pageInfo {
      hasNextPage
      endCursor
    }
  }
}
```

**Task:** Build a Next.js frontend that consumes your WordPress GraphQL API with ISR (Incremental Static Regeneration).

**Context:** Next.js is the most popular framework for headless WordPress. ISR allows you to have static pages that automatically regenerate when content changes.

### Requirements

1. Create Next.js 15 app with App Router
2. Install Apollo Client for GraphQL
3. Fetch data from WordPress GraphQL API
4. Implement ISR with revalidation
5. Add client-side navigation
6. Deploy to Vercel

### Part 1: Next.js Setup (10 min)

**Create Next.js App:**
```bash
npx create-next-app@latest my-headless-wp --typescript --tailwind --app
cd my-headless-wp
```

**Install Apollo Client:**
```bash
npm install @apollo/client graphql
```

**Create Apollo Client:**
```typescript
// lib/apollo-client.ts

const client = new ApolloClient({
  link: new HttpLink({
```

### Part 2: Fetch WordPress Data (15 min)

**Create GraphQL Query:**
```typescript
// lib/queries.ts
import { gql } from '@apollo/client';

export const GET_POSTS = gql`
  query GetPosts($first: Int = 10) {
    posts(first: $first, where: { status: PUBLISH }) {
      nodes {
        id
        title
        excerpt
        slug
        date
        author {
          node {
            name
          }
        }
        featuredImage {
          node {
            sourceUrl
            altText
          }
        }
      }
    }
  }
`;

export const GET_POST_BY_SLUG = gql`
  query GetPostBySlug($slug: String!) {
    postBy(slug: $slug) {
      id
      title
      content
      date
      author {
        node {
          name
          avatar {
            url
          }
        }
      }
      featuredImage {
        node {
          sourceUrl
          altText
        }
      }
    }
  }
`;
```

**Create Blog Page with ISR:**
```typescript
// app/blog/page.tsx
import client from '@/lib/apollo-client';
import { GET_POSTS } from '@/lib/queries';
import Link from 'next/link';
import Image from 'next/image';

export const revalidate = 3600; // ISR: Revalidate every hour

export default async function BlogPage() {
  const { data } = await client.query({
    query: GET_POSTS,
    variables: { first: 10 },
  });

  const posts = data.posts.nodes;

  return (
    <div className="container mx-auto px-4 py-8">
      <h1 className="text-4xl font-bold mb-8">Blog</h1>

      <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
        {posts.map((post: any) => (
          <article key={post.id} className="border rounded-lg overflow-hidden">
            {post.featuredImage && (
              <Image
                src={post.featuredImage.node.sourceUrl}
                alt={post.featuredImage.node.altText || post.title}
                width={400}
                height={250}
                className="w-full h-48 object-cover"
              />
            )}

            <div className="p-4">
              <h2 className="text-xl font-bold mb-2">
                <Link href={`/blog/${post.slug}`} className="hover:text-blue-600">
                  {post.title}
                </Link>
              </h2>

              <div
                className="text-gray-600 mb-3"
                dangerouslySetInnerHTML={{ __html: post.excerpt }}
              />

              <div className="text-sm text-gray-500">
                By {post.author.node.name} • {new Date(post.date).toLocaleDateString()}
              </div>
            </div>
          </article>
        ))}
      </div>
    </div>
  );
}
```

### Part 3: Dynamic Post Pages (15 min)

**Create Dynamic Route:**
```typescript
// app/blog/[slug]/page.tsx
import client from '@/lib/apollo-client';
import { GET_POST_BY_SLUG, GET_POSTS } from '@/lib/queries';
import Image from 'next/image';
import { notFound } from 'next/navigation';

export const revalidate = 3600; // ISR revalidation

// Generate static params for ISR
export async function generateStaticParams() {
  const { data } = await client.query({
    query: GET_POSTS,
    variables: { first: 100 }, // Generate first 100 posts
  });

  return data.posts.nodes.map((post: any) => ({
    slug: post.slug,
  }));
}

export default async function PostPage({ params }: { params: { slug: string } }) {
  const { data } = await client.query({
    query: GET_POST_BY_SLUG,
    variables: { slug: params.slug },
  });

  const post = data.postBy;

  if (!post) {
    notFound();
  }

  return (
    <article className="container mx-auto px-4 py-8 max-w-3xl">
      {post.featuredImage && (
        <Image
          src={post.featuredImage.node.sourceUrl}
          alt={post.featuredImage.node.altText || post.title}
          width={800}
          height={500}
          className="w-full rounded-lg mb-8"
          priority
        />
      )}

      <h1 className="text-4xl font-bold mb-4">{post.title}</h1>

      <div className="flex items-center gap-4 mb-8 text-gray-600">
        {post.author.node.avatar && (
          <Image
            src={post.author.node.avatar.url}
            alt={post.author.node.name}
            width={40}
            height={40}
            className="rounded-full"
          />
        )}
        <div>
          <div className="font-semibold">{post.author.node.name}</div>
          <div className="text-sm">{new Date(post.date).toLocaleDateString()}</div>
        </div>
      </div>

      <div
        className="prose prose-lg max-w-none"
        dangerouslySetInnerHTML={{ __html: post.content }}
      />
    </article>
  );
}
```

## Troubleshooting Common Issues

### Issue: CORS Errors

**Problem:** Frontend can't access WordPress API due to CORS policy.

**Solution:**
```php
// wp-content/themes/your-theme/functions.php
add_action('rest_api_init', function() {
    header('Access-Control-Allow-Origin: https://your-frontend.com');
    header('Access-Control-Allow-Methods: GET, POST, OPTIONS');
    header('Access-Control-Allow-Headers: Authorization, Content-Type');
}, 15);
```

### Issue: JWT Token Expired

**Problem:** Authentication fails after token expires.

**Solution:**
Implement token refresh logic in your frontend:
```typescript
// lib/auth.ts
export async function refreshToken(token: string) {
  const response = await fetch('https://your-site.com/wp-json/jwt-auth/v1/token/refresh', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`,
    },
  });

  return response.json();
}
```

### Issue: Slow GraphQL Queries

**Problem:** Queries taking multiple seconds to complete.

**Solution:**
- Use query complexity analysis
- Limit nested query depth
- Implement query caching
- Add pagination with reasonable limits

```graphql
# Good: Limited query
query GetPosts {
  posts(first: 10) {
    nodes {
      id
      title
      # Only request fields you need
    }
  }
}

# Bad: Unlimited query
query GetAllPosts {
  posts {
    nodes {
      id
      title
      content # Heavy field
      # Nested queries multiply load
      comments {
        nodes {
          content
          author {
            node {
              posts {
                nodes {
                  title # N+1 problem!
                }
              }
            }
          }
        }
      }
    }
  }
}
```
