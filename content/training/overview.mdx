# WordPress + Claude Code: Complete Training

**Transform your WordPress development workflow with AI-powered automation.**

This comprehensive training program takes you from Claude Code fundamentals to advanced AI-powered workflows, headless architectures, and production-ready automation. Whether you're building client sites, managing a WordPress agency, or developing enterprise applications, this curriculum gives you the skills to work 10x faster.

---

## Course Overview

### Time Commitment
- **Core Training (Weeks 1-8):** 16 hours | Required for all developers
- **Advanced Track (Weeks 9-12):** 8 hours | Optional specialization
- **Total:** 24 hours at 2 hours per week = 12 weeks self-paced

### What You'll Build
- CLAUDE.md configuration for your projects
- Custom Gutenberg blocks and ACF field groups
- Automated quality gates with hooks
- Complete AJAX features from scratch
- Production deployment workflows
- Block themes for WordPress 7.0
- Headless WordPress with Next.js
- AI-powered WordPress features

### Prerequisites
- Basic WordPress development knowledge (themes, plugins)
- Familiarity with PHP and JavaScript
- Git and command line basics
- Local WordPress development environment

## Self-Paced Learning

**This training is designed for self-paced learning.**

### Navigation
- **No forced linear progression** - Jump to any week (though we recommend completing prerequisites)
- **Track your progress** - Checkboxes on exercises automatically save your progress
- **Resume anytime** - Your progress persists across sessions
- **Skip what you know** - Already familiar with a topic? Move ahead

### Recommendations
1. **Start with Week 1** if you're new to Claude Code
2. **Complete Core Training (1-8)** before Advanced Track (9-12)
3. **Take your time** - Quality learning beats speed
4. **Practice each exercise** - Don't just read, build!
5. **Join the community** - Share your progress and ask questions

### Time Commitment Options
- **Intensive:** 2 hours/day = 2 weeks for core, 1 week for advanced
- **Steady:** 2 hours/week = 8 weeks for core, 4 weeks for advanced
- **Relaxed:** 1 hour/week = 16 weeks for core, 8 weeks for advanced

## Prerequisites Setup

Before starting Week 1, ensure you have:

### Required
- [ ] **WordPress Development Environment** - Local WordPress installation (LocalWP, MAMP, Docker, etc.)
- [ ] **PHP 8.0+** - Check with `php -v`
- [ ] **Node.js 18+** - Check with `node -v`
- [ ] **Git** - Check with `git --version`
- [ ] **Code Editor** - VS Code, PHPStorm, or similar
- [ ] **Claude Pro Subscription** - Required for Claude Code CLI access

### Recommended
- [ ] **ACF PRO** - Advanced Custom Fields plugin (used in Week 2+)
- [ ] **Query Monitor** - Performance debugging (used in Week 10)
- [ ] **WP-CLI** - WordPress command line interface
- [ ] **Composer** - PHP dependency management
- [ ] **PHPCS** - PHP CodeSniffer (used in Week 4)

### Test Your Setup
Run these commands to verify:
```bash
php -v          # Should show PHP 8.0+
node -v         # Should show Node 18+
git --version   # Should show Git 2.x+
wp --version    # (Optional) WP-CLI version
```
