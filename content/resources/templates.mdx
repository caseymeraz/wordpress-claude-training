Essential template files to get started with Claude Code in your WordPress projects.

## Hooks Configuration

The hooks.json file configures pre-commit hooks and automation for your Claude Code sessions. This template includes security checks, code quality tools, and WordPress coding standards.

  >
    ⚙️ Download Hooks Configuration
  </a>
</div>

### What's Included
- PHPCS (WordPress Coding Standards) integration
- PHPUnit test execution
- Security audit triggers
- Git commit message formatting
- Error log monitoring

### How to Use
1. Download the configuration above
2. Copy to `~/.claude/hooks.json` (global) or `.claude/hooks.json` (project-specific)
3. Customize patterns and commands for your workflow
4. Enable/disable hooks as needed

### Available Hook Types
- **pre-commit**: Run before creating commits
- **post-commit**: Run after commits succeed
- **on-error**: Trigger when errors occur
- **periodic**: Run at intervals during long sessions

## Using the Templates

### Step 1: Project Setup
```bash
# Navigate to your WordPress project
cd /path/to/wordpress-project

# Create .claude directory
mkdir -p .claude

# Copy CLAUDE.md template
cp /path/to/CLAUDE_MD_TEMPLATE.md .claude/CLAUDE.md

# Edit to match your project
nano .claude/CLAUDE.md
```

### Step 2: Configure Hooks (Optional)
```bash
# Copy hooks configuration
cp /path/to/HOOKS_CONFIG_TEMPLATE.json ~/.claude/hooks.json

# Or edit directly
claude hooks edit
```

### Step 3: Start Your First Session
```bash
# Start Claude Code in your project
claude

# Claude will now have context from your CLAUDE.md file
```

## Template Maintenance

### Keep Templates Updated
As your project evolves, remember to update your CLAUDE.md file:
- ✅ After adding new ACF field groups
- ✅ When creating new custom post types
- ✅ After installing new plugins
- ✅ When project requirements change
- ✅ After architecture decisions

### Version Control
Consider committing `.claude/CLAUDE.md` to your repository so the entire team has consistent context. Exclude sensitive information like API keys.

```bash
# Add to git
git add .claude/CLAUDE.md
git commit -m "Add Claude Code context file"
```
